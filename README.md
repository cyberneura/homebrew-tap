# homebrew-tap

Homebrew tap for Cyberneura tools.

## Formulae

### taskshoot

Taskshoot task operations CLI (AI-agent friendly).

```shell
brew install cyberneura/tap/taskshoot
```

## Casks

### QueryFolio

Multi-purpose SQL GUI client (macOS).

```shell
brew install --cask cyberneura/tap/queryfolio
```
